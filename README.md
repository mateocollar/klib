# klib

![Version](https://img.shields.io/badge/version-0.1.0-blue)
![CI](https://github.com/KhronosDevs/klib/actions/workflows/ci.yml/badge.svg)

Native C library for [KhronosDevs/PocketMine-MP](https://github.com/KhronosDevs/PocketMine-MP). Provides high‑performance utils.

**Installation is automatic** – the precompiled `libklib.so`/`libklib.dll` is bundled in the main project under `libs/`.

> Maintained internally. External contributions are not accepted.
